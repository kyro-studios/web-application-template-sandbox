# 要件定義書: フッターの著作権の表記

## 1. 目的

アプリケーションの提供元を、利用者がどの画面からも確認できるようにする。そのため、すべての画面の下部に共通のフッターを表示し、著作権の表記を載せる。

## 2. 範囲

### 2.1 この機能で扱うこと

- すべての画面に共通のフッターの表示
- フッターへの著作権の表記の表示

### 2.2 この機能で扱わないこと

- 利用規約やプライバシーポリシーなど、ほかのページへのリンク
- フッターの表記を、画面から変更すること
- 画面ごとに、フッターの表示を変えること

## 3. 用語

| 用語 | 意味 |
| --- | --- |
| 利用者 | アプリケーションを使う人。ログインしているかどうかは問わない |
| フッター | すべての画面の下部に共通で表示する領域 |
| 著作権の表記 | アプリケーションの提供元と年を示す 1 行の文字列 (例: `© 2026 Kyro Studios`) |

## 4. 機能要件

- FR-1: すべての画面の下部に、共通のフッターを表示する。ログインしていない利用者にも表示する
- FR-2: フッターには、著作権の表記を 1 行で表示する。形式は `© <年> Kyro Studios` とする
- FR-3: 著作権の表記の年は、固定の値にせず、画面を表示した時点の年 (日本時間 (Asia/Tokyo) の年) にする
- FR-4: フッターは、画面の内容の後に表示する。画面の内容が短い場合も、内容の直後に表示すればよく、ブラウザーの表示領域の下端に固定しなくてよい

## 5. 非機能要件

- NFR-1: フッターの表示のために、サーバーとの通信を増やさない。表記は画面の中だけで組み立てる
- NFR-2: フッターは、スクリーンリーダーなどの支援技術が、ページのフッターとして認識できる要素で作る

## 6. 前提

- 利用者は、ブラウザーでアプリケーションを使う
- この機能は、ほかの機能 (ユーザーの認証機能 #1、お知らせの一覧 #35) に依存しない
- この機能は、仕組みの動作確認のための小さな機能である
