# 要件定義書: ユーザーの認証機能

## 1. 目的

利用者が自分のアカウントを作り、ログインしてアプリケーションを使えるようにする。あわせて、利用者が自分のアカウントの情報を変更したり、アカウントを削除したりできるようにする。

## 2. 範囲

### 2.1 この機能で扱うこと

- 利用者自身によるアカウントの作成 (利用者登録)
- ログインとログアウト
- 利用者自身によるアカウントの情報 (表示名、メールアドレス、パスワード) の変更
- 利用者自身によるアカウントの削除

### 2.2 この機能で扱わないこと

- 管理者による、ほかの利用者のアカウントの作成、変更、削除
- パスワードを忘れたときの再設定
- メールアドレスの確認 (確認用のメールの送信)
- 外部のサービスのアカウントを使ったログイン (ソーシャルログイン)
- 多要素認証
- 権限や役割による、使える機能の出し分け

## 3. 用語

| 用語 | 意味 |
| --- | --- |
| 利用者 | アプリケーションを使う人 |
| アカウント | 利用者を識別するための登録情報。メールアドレス、表示名、パスワードを持つ |
| ログイン中 | 利用者が本人であることを確かめた後、ログアウトするか一定時間が経つまでの状態 |

## 4. 機能要件

### 4.1 利用者登録

- FR-1: ログインしていない利用者は、メールアドレス、表示名、パスワードを入力して、アカウントを作成できる
- FR-2: ほかのアカウントで使われているメールアドレスでは、アカウントを作成できない。その場合は、作成できなかったことを利用者に知らせる
- FR-3: 入力が条件 (5 章) を満たさない場合は、アカウントを作成せず、どの入力がどの条件を満たしていないかを利用者に知らせる
- FR-4: アカウントを作成したら、そのままログイン中の状態になる

### 4.2 ログインとログアウト

- FR-5: 利用者は、メールアドレスとパスワードを入力してログインできる
- FR-6: メールアドレスかパスワードが誤っている場合はログインできない。その場合、メールアドレスとパスワードのどちらが誤っているかは知らせない
- FR-7: ログイン中の利用者は、ログアウトできる。ログアウトした後は、ログインが必要な操作を行えない
- FR-8: ログイン中の状態は、最後の操作から 30 分間操作が無ければ終わる

### 4.3 アカウントの情報の変更

- FR-9: ログイン中の利用者は、自分の表示名とメールアドレスを変更できる
- FR-10: メールアドレスを変更するときも、FR-2 と同じく、ほかのアカウントで使われているメールアドレスには変更できない
- FR-11: ログイン中の利用者は、今のパスワードを入力したうえで、パスワードを変更できる。今のパスワードが誤っている場合は変更できない
- FR-12: 利用者は、ほかの利用者のアカウントの情報を見たり変更したりできない

### 4.4 アカウントの削除

- FR-13: ログイン中の利用者は、パスワードを入力したうえで、自分のアカウントを削除できる。パスワードが誤っている場合は削除できない
- FR-14: アカウントを削除したら、ログイン中の状態は終わり、そのアカウントではログインできなくなる
- FR-15: 削除したアカウントのメールアドレスは、新しいアカウントの作成に使える

## 5. 入力の条件

| 入力 | 条件 |
| --- | --- |
| メールアドレス | メールアドレスの形式であること。254 文字以内 |
| 表示名 | 1 文字以上 50 文字以内。前後の空白は取り除く |
| パスワード | 12 文字以上 128 文字以内 |

## 6. 非機能要件

### 6.1 セキュリティ

- NFR-1: パスワードは、保存した情報から元のパスワードを復元できない形で保存する
- NFR-2: 同じメールアドレスに対して、ログインに 5 回続けて失敗した場合は、そのメールアドレスでのログインを 15 分間受け付けない
- NFR-3: パスワードやログイン中の状態を表す情報は、画面、ログ、エラーメッセージに出力しない
- NFR-4: ログインやアカウントの情報の送受信は、暗号化された通信で行う

### 6.2 性能

- NFR-5: 同時に 100 人の利用者が操作している状態で、利用者登録、ログイン、アカウントの情報の変更の各操作は、95% が 1 秒以内に完了する

### 6.3 運用

- NFR-6: 利用者登録、ログインの成功と失敗、アカウントの情報の変更、アカウントの削除は、日時と対象のアカウントを含めて記録する。記録にはパスワードを含めない
- NFR-7: 記録は 90 日間保存する

## 7. 前提

- 利用者は、ブラウザーでアプリケーションを使う
- アカウントの作成に、管理者の承認は不要とする
